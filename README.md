## Open Source

**[Aspectify](https://github.com/muhammedalikcb/aspectify)** &nbsp; ![Stars](https://img.shields.io/github/stars/muhammedalikcb/aspectify?style=flat-square) ![Top language](https://img.shields.io/github/languages/top/muhammedalikcb/aspectify?style=flat-square) ![License](https://img.shields.io/github/license/muhammedalikcb/aspectify?style=flat-square)

Annotation-based AOP framework for Kotlin and Android, built on Kotlin Reflection and Dynamic Proxy. It applies retry, logging, and timeout around annotated calls with minimal boilerplate, keeping cross-cutting concerns out of business logic. Contributions and issues welcome.

**[SecureCheck](https://github.com/muhammedalikcb/securecheck)** &nbsp; ![Stars](https://img.shields.io/github/stars/muhammedalikcb/securecheck?style=flat-square) ![Top language](https://img.shields.io/github/languages/top/muhammedalikcb/securecheck?style=flat-square)

Mobile security reference app running 25+ runtime and system-integrity checks: root, SSL pinning, Frida and Xposed, SafetyNet, emulator, and debugger detection. Built with Clean Architecture, Dagger 2, Jetpack Compose, and MotionLayout.

More samples, including Mealz (Compose) and Exzi (crypto trading UI), are on [my GitHub profile](https://github.com/muhammedalikcb).

## Open Source

**[Aspectify](https://github.com/muhammedalikcb/aspectify)** &nbsp; [![Top language](https://img.shields.io/github/languages/top/muhammedalikcb/aspectify?style=flat-square)](https://github.com/muhammedalikcb/aspectify) [![License](https://img.shields.io/github/license/muhammedalikcb/aspectify?style=flat-square)](https://github.com/muhammedalikcb/aspectify/blob/main/LICENSE)
Annotation-based AOP library for Kotlin and Android on Maven Central, built on Dynamic Proxy. Adds logging, retry, timeout, caching, rate limiting, and role checks around annotated calls.

**[SecureCheck](https://github.com/muhammedalikcb/securecheck)** &nbsp; [![Top language](https://img.shields.io/github/languages/top/muhammedalikcb/securecheck?style=flat-square)](https://github.com/muhammedalikcb/securecheck)
Android reference app that runs 23 device and app integrity checks (root, Frida, Xposed, emulator, debugger, tampering, Play Integrity, SSL pinning). Clean Architecture, Dagger 2, Compose, MotionLayout.
